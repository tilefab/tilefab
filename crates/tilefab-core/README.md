# tilefab-core

Common base of [tilefab](https://crates.io/crates/tilefab): cells, buffer, styles, geometry, styled text and the widget traits.

**This is an internal crate of tilefab: depend on [`tilefab`](https://crates.io/crates/tilefab) instead**,
which re-exports its API. It is published only because `tilefab` needs it, and its version always
moves together with `tilefab`'s.
